# CPD Pocket

Log CPD in seconds, keep certificates with each activity, and see whether you're on track for renewal.

- Progress ring with pace ("about 3 h a week to finish by 31 Dec")
- Certificates and evidence (photo or PDF) attached to each activity
- Reflection prompts: what you learned, and how it changes your practice
- Credentials tab: licence, BLS, indemnity, with expiry warnings and calendar reminders (.ics)
- CSV export and a printable PDF record
- Backup and restore to a single file

Everything is stored in the browser. There's no account and nothing is uploaded.

Live: https://drw-21.github.io/cpdpocket/
